# IPL Matches Data Analysis (2008 – 2024)

An Exploratory Data Analysis (EDA) and data preprocessing pipeline for the Indian Premier League (IPL) matches dataset (2008–2024), built using `pandas` in Python.

## 📌 Project Overview
This repository contains a Jupyter Notebook demonstrating data loading, inspection, cleaning, and preprocessing steps on historical IPL match record data.

The dataset tracks match results, teams, venues, toss outcomes, result margins, and match officials across 1,095 total recorded matches.
